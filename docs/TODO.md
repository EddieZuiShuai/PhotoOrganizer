### 1.5 (21) · 2026-11-06

- **隐私视频**：`ContentCategory` 新增 `.privacyVideo`，视频在内容识别阶段不再被整段跳过。用封面帧做免费闸门，封面有肤色才补抽 30% / 65% 两帧（`AVAssetImageGenerator`，`appliesPreferredTrackTransform` 必开，否则竖拍视频坐标差 90°），取最高分；命中写入 `.privacyVideo` 并进分类桶。视频只认这一类，其余分类不认视频。
- **两个隐私分类**：`.privacy` 改名为「隐私照片」，新增「隐私视频」。分类总览两张卡都出现，由 `showPrivacyCategory` 一起控制；`== .privacy` 的特判全部收敛成 `category.isPrivacy`（五处：建议清理、清理页页签、分类卡片过滤、缩略图打码、关开关时退回）。
- **隐私判定 v3**：新增**躯干闸门** `torsoRatioFloor = 0.32`——人脸框外扩 18% 之后，剩下的「非脸人体」至少要占人体的 32%，否则直接判 0。专治头像照 / 证件照 / 只露头：这类照片整张人就是一个头，分子分母都很小反而比值极高，v2 会把它们判成隐私。绝对量系数同时从 4% 提到 5%（脖子＋锁骨的近景容易占 4%，正好卡在旧阈值上）。
- **隐私口径迁移**：`privacyModelVersion`（UserDefaults）一次性迁移，`ScanCache.resetPrivacyJudgements()` 只把旧的隐私结论放回未识别（几十到几百条，重判约一分钟），**不动 `Cache.version`**，其余两万条照常命中。
- **分类就地下钻**：分类 tab 包 `NavigationStack`，点卡片 push 到 `CategoryDetailView`（三列网格 + 全选 + 就地删除 + 大图预览 + 视频可播），不再跳回清理 tab。原来那个跳转等于把用户扔到另一个上下文，且回不去。
- **逐张过升级**：从右上角工具栏挪进列表上方，变成整行入口「逐张过 · N 项 · 左右滑快速筛」。**评估结论是不做第五个 tab**：它是「对当前列表的动作」，放进 tab 就得在 tab 里重选一次分类，把上下文扔掉重来；而且张数是这个入口最重要的信息，tab 图标放不下。
- **新手教程**：5 页（扫描预期 / 数字含义 / 选中与删除 / 逐张过 / 四个 tab + 隐私），每页「动作式标题 + 假 UI 示意图 + 一句记忆句」，5 个示意图全用组件现画、不引用 `AnalysisResult`（未授权相册也能看）。`tutorialSeenVersion` 存版本号而不是 Bool，翻到第 5 页才写。入口在「我的 → 帮助与支持」。
- **技术债**：删掉死代码 `AnalysisEngine.blurThreshold`（全项目零引用）；网格布局补「算清晰」入口（左下角，原来只在列表布局右侧有）。
- **默认值与视频 bug（1.5/21 追加）**：隐私两个开关默认值改成「不显示（`showPrivacyCategory = false`）+ 模糊显示（`blurPrivacyThumbnails = true`）」，三处 `@AppStorage` 声明同步；修逐张过视频「点喇叭会顺带暂停」——喇叭按钮原本是播放/暂停 `simultaneousGesture` 的子视图，点它等于「取消静音 + 暂停」一起发，已摘出成独立覆盖层（不再触发播放/暂停）。

## 已完成

### 1.4 (18) · 2026-11-05

- **增量扫描**：`ScanCache` 按 `localIdentifier + modificationDate` 缓存特征与内容识别结果，二次扫描整段跳过
- **断点续扫**：每 800 张落盘，被杀后最多重算最后 800 张（增量本身就是续扫，不设单独按钮）

- **放大角标统一**：列表 / 网格 / 分组卡片同一套 `zoomBadge`，右上角
- **取消文案**：「取消」→「取消选中 N 张」，顶部「清空」同步

## 已完成

### 1.5 (29) · 2026-11-07

第二轮真机反馈六条（另两条是答疑）。

- **大图预览加「隐藏」**：隐私组的大图底部变成三颗「待删 / 隐藏 / 立即删除」，`PhotoPreviewView` 新增 `isPrivacy` + `onHide`。隐藏成功后直接关预览——这张已经从 App 的列表里消失了，停在一个不存在的条目上只会让人以为点空了。清理页和分类页各补一个 `hideOne(_:)`，和批量那条共用 `setHidden` + `friendlyPhotoError`。
- **统一叫「待删」**：大图那颗从「标记待删」改成「待删」，标记后是「取消待删」。同一个动作在逐张过、清理页、大图三处必须同名，否则用户会以为是三件不同的事。
- **错误码不上界面**：新增 `friendlyPhotoError(_:)`。`PHPhotosErrorDomain 错误 3072` 只进 `NSLog`，界面说「系统把这次操作取消了（切到别的 App、或者系统弹窗被关掉都会这样），再试一次就好」。3072 = `PHPhotosError.userCancelled`，真机上相册忙的时候会**偶发**，`setHidden` 里已经自动重试一次。3303（原图在 iCloud）、3142/3102（资源被占）也各有对应人话。
- **「从头再筛一遍」后入口还显示「已看 7」**：`TriageProgressStore` 原来是纯 class，`judgedCount()` 是普通 getter，`clear()` 之后没有任何通知，入口那行就挂着旧数字。改成 `ObservableObject` + `@Published revision`，四个写操作各 `&+= 1`，`ResultView` / `CategoryDetailView` 用 `@ObservedObject` 订阅。
- **下滑关掉逐张过会丢标记**：只有点 X 才走 `finish()`。补 `.onDisappear` 兜底，`finished` 标志防重复回调。顺带解决「没看到『已选 N … 可以删除，也可以隐藏』」——原来那条 toast 根本没机会执行。
- **逐张过 LIVE 挪到左下角**：从右上角 9pt 小药丸改成和全屏预览一致的大胶囊（13pt 图标、12×9 内边距），静音键一起搬过来（40×40，原来 32）。卡片底部文件信息条相应上移 44pt，避免压住按钮。
- **「系统权限」里加一行「网络」**：iOS 没有联网授权这一项，所以这一行**只能写说明、不能做开关**（做个开关就是假的）。写清「只在取 iCloud 原图时联网，不上传任何照片」，点进去是同一张 `CloudNoticeCard`。

### 1.5 (28) · 2026-11-07

真机反馈四条，两条是系统限制、两条是真问题。

- **「已隐藏的照片」永远是空的 —— 这是 iOS 限制，不是 bug。** Apple 文档：从 iOS 16 起用户可以要求 Face ID 才能看隐藏相簿，**该设置默认打开，此时系统返回一个空相簿**；开发者论坛里 Apple 工程师确认没有任何 API 能绕过，只能弹 `PHPickerViewController` 让用户手选。所以：空态从「没有已隐藏的照片」改成说明页 + 「打开系统「照片」App」按钮；隐藏确认弹窗和 toast 全部改口，不再承诺「在 App 里可找回」。新增 `hiddenEverCount` 只用于区分「真没藏过」和「藏过但读不到」。
- **逐张过单张隐藏**：隐私组底部第五颗按钮（`eye.slash`），只作用于当前这一张，和「待删」彻底分开——待删是攒着一起删，隐藏是立刻挪走。隐藏成功后从列表移除、`judged` 记录一并摘掉（不是记成判过：它已经从相册消失，万一以后在系统相册取消隐藏，应该重新被问一次）、回调 `onHide` 让网格立刻少一格。因为 iOS 读不回，这里**不做撤销**，hint 直接写「去「照片」App 的「已隐藏」可取消」。
- **选中态的语义**：隐私组选中后，底部条上方加一行 10.5pt 说明「「删除」会进最近删除；「隐藏」只是挪进系统相簿，照片还在」。逐张过回列表的 toast 从「已标 N 张待删」改成「已选 N 项 · 可以删除，也可以隐藏」。
- **修 Live 播放残影（顶部一条重复内容）**：`LivePhotoStage` 原来把 `PHLivePhotoView` 直接丢进 ZStack，它拿到的是 TabView 页面的安全区尺寸，和 `ZoomableImageView`（全屏 + `ignoresSafeArea` + `scaledToFit`）对不上。现在按 `asset.pixelWidth/pixelHeight` 算出 fit 后的矩形，精确设成动态层的 frame，再加 `.clipped()` 兜住像素级溢出。

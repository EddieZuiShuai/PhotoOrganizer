# 新手教程 · 内容与呈现规格

> 版本：`1.5 (21)` 计划项（见 `TODO.md` 的「下个版本」）
> 状态：**未实现**。这份文件是给实现者的唯一口径，改教程先改这里。
> 关联：入口在「我的」，呈现规则要同时满足 `DESIGN.md` 的视觉 token 与文案语气。

## 1. 目标与非目标

**目标**：让第一次用的人在**第一次扫描跑完时**不困惑、不当它是卡死、不误删。

**非目标**（写清楚，避免实现时加戏）：

| 不做 | 原因 |
|---|---|
| 教全部功能 | 十节用户手册搬进 App = 没人看完。只留"第一次就会撞上"的 5 件事 |
| 蒙层挖洞（spotlight）指向真实控件 | 教程必须在**没有任何结果数据**时也能看（首屏、未授权）；且结果页标签按数据动态生成，坐标不稳。改一次版就全失效 |
| 强制全屏、必须看完才能扫 | 扫描本身十几分钟，第一屏的耐心最贵。多两次点击就是在赶人 |
| 截图 / 录屏 / GIF | 改一次字号全过期，还要维护 @2x/@3x 两套。示意图用 SwiftUI 画，自动跟随主题 |
| 记"看到第几页" | 只有 5 页，续看比重看更怪，还多一个状态要维护 |
| 任何埋点 | 铁律 1：不引入网络。验收靠人和 Maestro |

## 2. 入口：一个必须正视的结构问题

**底部 tab 不是一直在的。** `HomeView`（首屏）→ 点「开始扫描」→ 扫描中 → 扫描完成后才进 `MainTabView`，四个 tab 这时才出现。

所以：

- 只在「我的」放入口 = **新用户永远看不到**（他要先等十几分钟扫描完，才有「我的」）。
- 「我的」里的入口真正的作用是**随时回看**，不是第一次触达。

因此设计成两个入口，**但两者都指向同一个 `TutorialView`**，内容零重复：

| 入口 | 位置 | 出现条件 | 定位 |
|---|---|---|---|
| A. 我的 → 帮助与支持 → 新手教程 | `SettingsTabView` 新增「帮助与支持」组的第一行 | **永远显示** | 随时回看（你点名的那个） |
| B. 首页提示卡 | `HomeView` 里「开始扫描」按钮**下方** | `tutorialSeenVersion == ""` | 第一次触达（**候选，需确认**） |

> B 是候选，不是默认范围。不做 B 也能上线，只是新用户只能靠"自己去我的里找"。
> 若做 B，位置必须在按钮**下方**、版本号上方：**不能推动「开始扫描」的位置**，否则 8 条 Maestro 用例的首屏步骤全部要改。

## 3. 呈现方式

### 3.1 载体

`.sheet` + `.presentationDetents([.large])` + `.presentationDragIndicator(.visible)`。

不用 `fullScreenCover`：它没有下滑关闭手势，得自己加关闭按钮和层级，与 `DESIGN.md` 的「Modal 必须可下滑关闭」冲突。

### 3.2 翻页

`TabView(selection: $page)` + `.tabViewStyle(.page(indexDisplayMode: .never))` + **自绘圆点**（系统圆点在浅灰底上对比度不足 3:1，且没法调大小）。

> 这里用系统 `TabView` 是**安全的**，不和「底部四 tab 不能用 TabView」的铁律冲突：
> 那条铁律的理由是切走会销毁页面、丢 `selectedIDs`；教程页是纯静态内容，销毁不丢任何东西。
> 实现时在代码里留一行注释说明这个区别，否则下一个人会以为违反了铁律。

### 3.3 每页骨架（三块，8pt 网格）

```
┌ 步骤序号 01 / 05 ────────────────┐   11 号字，secondary
│ 标题（一句动作，22 semibold）      │   只读标题也能知道该干嘛
│ 正文（14，最多 3 行）              │
├ 示意图（白卡片，14 圆角，高 250）  │   纯 SwiftUI 假 UI
├ 记忆句（浅底小条，13）             │   一页只留一句能背下来的
└ ● ● ○ ○ ○        [ 下一步 ]  ────┘   圆点 + 17 semibold 主按钮
```

规则：
- **标题必须是动作**，不是功能名。「先让它扫完，中途别锁屏」而不是「扫描」。
- 正文最多 3 行，超了说明这页塞了两件事，拆页或砍。
- 记忆句用左侧 3pt 竖条 + 浅底（`#F5F5F7`），不用彩色底——彩色留给真正的状态。
- 最后一页主按钮文案：未扫描过 → 「开始扫描」（点完关闭并触发 `onStart`）；已扫描过 → 「知道了」。
- 右上角不放关闭按钮，靠下滑手势 + 最后一页按钮。若要加，只能放 `xmark`，`accessibilityIdentifier("tutorial-close")`。

### 3.4 示意图一律"假 UI"

每页一个 `private struct XxxMock: View`，用真实组件画假数据，**不引用 `AnalysisResult`**（教程必须在没数据时能看）。

| 页 | Mock 名 | 画什么 |
|---|---|---|
| 1 | `ScanMock` | 顶部胶囊横幅「正在识别内容 43%」+ 细进度条 + 下面 6 个灰色方块 |
| 2 | `StatsMock` | 四个数字块（建议清理 128 / 重复 6 / 发票 32 / 截图 91）+ 一排假标签 |
| 3 | `SelectMock` | 3×3 方块，3 个带蓝框 + 右下勾，底部红条「删除 3 张」 |
| 4 | `SwipeMock` | 一张卡片（灰占位 + 中下播放角标下方四按钮：撤销/保留/标记/删除） |
| 5 | `TabBarMock` | 四个 tab 一行，选中「清理」，右侧小箭头指向「我的」 |

## 4. 五页内容（逐页脚本）

### 第 1 页 · 扫描

- **标题**：`先让它扫完，中途别锁屏`
- **正文**：第一段一两分钟就出结果，看到清单就能开始挑；第二段在后台补内容分类，顶部横幅「正在识别内容 x%」走完才算全部完成。这期间锁屏、切到别的 App，会掐断正在识别的那几张。
- **记忆句**：`第二次扫描只要几十秒——没改过的照片直接读上次结果。`
- **要点来源**：`user-guide.md` 第 3 节。这一页治的是"横幅一直在跑，以为卡死"。

### 第 2 页 · 结果页怎么读

- **标题**：`百分比是「可疑度」，不是「该删的概率」`
- **正文**：80% 只表示这张同时命中了几个可疑特征，不代表八成该删。重复组最可信（原图字节完全一样）；相似看清晰度；模糊统一跟全库中位数比，阴天、夜景天然偏低。
- **记忆句**：`先看「重复」，这一组几乎不会错；再从建议清理最上面往下走。`
- **要点来源**：`user-guide.md` 第 4 节 + 「数字的含义」。这一页治的是最容易被误读的数字。

### 第 3 页 · 选中与删除

- **标题**：`点一下是选中，红色按钮才是删`
- **正文**：选中会跨标签保留——在「重复」里选几张、切到「相似」再选几张，底部数字会累加。超过 500 张会先问一次。删掉的照片在「照片」App 的最近删除里留 30 天，可以恢复。
- **记忆句**：`扫描本身不改任何照片；只有你点删除，才会真的删。`

### 第 4 页 · 逐张过

- **标题**：`左滑是「标记」，不是删`
- **正文**：右滑保留、左滑标记待删，底下的深红「删除」才是立刻删（会先问一次，删完不退出，继续下一张）。标记只是暂存，回列表点红按钮才真删。视频点封面中间就能播，默认静音，划走自动停。
- **记忆句**：`真删不能在这一页撤销——删一张会让后面的位置全部前移，做半残的撤销不如不做。`
- **要点来源**：`user-guide.md` 第 6 节。这一页治的是最危险的一次误操作。

### 第 5 页 · 四个 tab 与隐私

- **标题**：`四个 tab，各管一件事`
- **正文**：清理=干活的地方；分类=一屏看全九类各多少张；空间=谁在吃空间；我的=开关、缓存、权限、版本。
- **隐私**（同一页的第二段）：隐私是单独一类，判定口径是「排除人脸之后、身体上裸露皮肤偏多」。它**不进建议清理**，全选也带不走。
- **记忆句**：`隐私组误判很正常，最终点删除的永远是你自己。`

## 5. 状态

只有一个键：

| 键 | 类型 | 默认 | 写入时机 |
|---|---|---|---|
| `tutorialSeenVersion` | String | `""` | 翻到第 5 页并点完成时，写入 `CFBundleShortVersionString`（即 `"1.5"`） |

- 存**版本号**而不是 Bool：1.6 加了大功能要再引导一次，改一个值就行，不用加新键、不用清 UserDefaults。
- 首页卡片出现条件 = `tutorialSeenVersion == ""`。
- 中途关掉不写 → 卡片还在（避免"点开瞄一眼就永久消失"）。
- 「我的」入口不受版本影响，永远可点，每次从第 1 页开始。

## 8. 验收标准

1. 全新安装（删 App 重装）→ 首次进「我的」→「新手教程」可点开 → 5 页都能翻到底 → 点完成后关闭，回到「我的」。
2. **未授权相册权限**时打开教程，5 页全部正常显示、不崩、不请求权限。
3. 中途下滑关闭 → 再进来从第 1 页开始（不是第 3 页）。
4. iPhone SE（375×667）到 Pro Max（430×932）全部不截断：标题不换行、正文不超过 4 行、示意图不被压扁。
5. Dynamic Type 调到最大字号，正文仍可完整滚动查看（示意图可等比缩放，允许出现滚动）。
6. `09_tutorial.yaml` 在云端 CI 通过。
7. 若实现首页卡：8 条既有 flow 不加任何步骤仍全绿。

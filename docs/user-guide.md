# 使用说明

面向使用者。想看"为什么这么设计"去看 `project-overview.md`；这里只讲怎么用、数字怎么读、出问题怎么办。

## 1. 装到手机上

这个 App 没有上架 App Store，用自签名方式安装。

1. 在 GitHub 仓库的 **Actions** 里打开最新一次绿色构建，下载 `PhotoOrganizer-ipa-macos-15`，解压得到 `PhotoOrganizer.ipa`。
2. 手机用数据线连电脑，Windows 上打开 **Sideloadly**，把 ipa 拖进去，填 Apple ID，点 **Start**。
3. 装完后第一次打开会提示"未受信任的开发者"：到 **设置 → 通用 → VPN 与设备管理**，信任你的 Apple ID 证书。
4. 免费 Apple ID 签的证书 **7 天过期**，过期后 App 打不开，需要重新签一次（照片和设置不受影响）。

> 工作区根目录有个 `一键重签安装.cmd`（不在本仓库里），双击它会检查设备连接并拉起 Sideloadly，省得手动找包。

## 2. 第一次打开

1. 点「开始扫描」，系统会问相册权限。
2. **选「允许访问所有照片」。** 选"部分照片"只会扫到你勾的那几张，首页会显示"仅部分照片（建议改成全部）"。
3. 回到 App，首页会显示照片数和视频数。数字对得上再往下走。

## 3. 扫描：会分两次出结果

点「开始扫描」后：

- **第一段（通常一两分钟，取决于相册大小）**：算完重复、相似、模糊、截图，结果页直接出现，可以开始挑了。
- **第二段（后台）**：顶部会有一条横幅「正在识别内容 x%」。这一段的活是内容分类和发票识别，比第一段慢得多。横幅消失 = 全部完成。

扫描期间**别锁屏、别切到别的 App**。锁屏会让系统掐断正在解码的图和识别请求。不过现在就算被掐断也不用从头来，见下一节。

> 扫描本身不改动任何照片。只有你点删除，才会真的删。

### 第二次扫描会快很多（1.4(18) 起）

App 会把每张照片算出来的结果存在手机本地。再扫的时候：

- **没动过的照片**：直接读上次的结果，不取图、不跑识别。
- **新拍的照片 / 修过的照片**：才重新算。
- **中途被打断**：已经算过的都留着，下次从断的地方接着跑，最多重算最后 800 张。

所以第一次十几分钟跑完之后，日常再扫通常是**几十秒**。

## 4. 结果页怎么读

顶部先给四个数字：**建议清理 / 重复组 / 发票 / 截图**（发票在识别没跑完时显示「…」，不是 0）。右侧两个按钮：**筛选**（时间段 / 相册）、**逐张过**。下面按类分标签。

**底部有四个 tab**（1.4(20) 起）：**清理 / 分类 / 空间 / 我的**。清理就是这一页；分类是一屏看全九类内容的张数和体积；空间是体积看板；我的是版本号和重新扫描。切 tab 不会丢已选、也不会丢滚动位置。

| 标签 | 里面是什么 | 建议怎么处理 |
|---|---|---|
| **建议清理** | 综合可疑度从高到低排 | 从最上面往下看，先处理 80% 以上的 |
| **重复** | 原图字节完全相同的组 | 每组留一张，其余可删。这个最可信 |
| **相似** | 连拍、角度几乎一样 | 留最清晰那张，其余删 |
| **模糊** | 清晰度明显低于本相册中位数 | 逐张看；误判的切到单列，点右侧「算清晰」排除 |
| **大文件** | 按体积从大到小 | 视频优先看，可转 720p |
| **内容分类** | 发票票据 / 文档 / 截图 / 人物 / 美食 / 风景 / 宠物 / 隐私 / 其他 | 发票、文档建议整类保留；截图可整批清 |
| **隐私** | 排除人脸之后、人体区域里裸露皮肤偏多的 | 不进「建议清理」，不会在你顺手全选时被带走。**当前版本缩略图暂不打码**（1.4(19) 起为校准误报临时关闭），方便逐张核对；恢复默认打码只改一个开关 |

### 每张缩略图右上角的 ⤢

点它 = 看大图。列表、网格、分组卡片三个地方都有，位置和样式完全一样。
点图片本身是「选中」，两者不会冲突。

### 数字的含义

- **建议清理的百分比**：综合可疑度，不是"删除概率"。80% 表示"这张同时满足了几条可疑特征"，不表示"八成该删"。
- **清晰度分（0~100）**：100 ≈ 本相册的中位清晰度。23 分表示比大多数照片糊，但阴天、夜景、室内本身就会偏低。
- **可释放空间**：重复组每组保留一张后的理论值 + 模糊 + 截图，不是"删了就一定省这么多"。

## 5. 选中与删除

1. **点一下**照片 = 选中（蓝框），再点一下取消。
2. **点缩略图右上角的 ⤢** = 看大图（可缩放；视频可直接播放）。长按同样能放大，但角标才是主入口。
3. 选中会**跨标签保留**：在"重复"里选几张，切到"相似"再选几张，底部数字会累加。
4. 点底部红色「删除 N 张」。**超过 500 张会先弹一次确认**。
5. 想全部取消，点底部左边那个按钮，或顶部红色的「取消选中 N 张」。文案里带数量，按下去会发生什么是明确的。
6. 删掉的照片在「照片」App 的 **最近删除** 里保留 30 天，可以恢复。

三种列宽（单列 / 两列 / 三列，默认三列）在标签下面那条工具条的右侧切换；分组页（重复 / 相似）没有这个按钮，因为分组必须按组看。

## 6. 逐张过（适合大批量快速筛）

点「逐张过」，进入全屏卡片：

照片一律**完整显示**（宁可上下留黑边，也不裁掉画面边缘）；视频显示封面 + 播放角标，点一下就能在卡片里播。

- **右滑 / 点绿色「保留」** = 留下
- **左滑 / 点橙色「标记」** = 标记待删（回列表再统一删）
- **点深红「删除」** = 立刻真删，会先问一次；删完不退出，继续下一张
- **点「撤销」** = 回到上一张（只对「保留 / 标记」有效，真删不能在这里撤销）
- 直接跳过也算保留

过完一批会显示「看了 N 张 · 标记删除 M 张 · 预计可释放 X」。

> **标记只是暂存**，不会立刻删。回到列表点红色按钮才真正删除。关掉逐张过时，标记会带回列表并自动选中。
>
> 真删掉的照片在系统「最近删除」里保留 30 天，可以恢复，但**不在这个页面里撤销**——删一张会让后面所有照片的位置前移，做半残的撤销不如不做。

**视频怎么播**：封面中央的播放角标点一下开始，再点暂停；右上角喇叭切换声音（**默认静音**）。划走会自动停，不会几个视频一起在后台响。

## 7. 空间看板与视频压缩

- **空间**：底部 tab 里的第二项，按分类看体积分布，用来找"谁在吃空间"。时间段 / 相册筛选在清理页顶部的**筛选**里。
- **视频转 720p**：在大文件里选视频，触发压缩。导出后如果只小不到 3%，会放弃替换原片（说明它本来就不大）。压缩成功会删掉原视频，30 天内可在最近删除找回。

## 8. 我的（设置）

底部第四个 tab，四组：

**显示与内容**

- **显示隐私分类**：关掉后，「清理」页的隐私页签和「分类」页的隐私卡片一起消失。照片还在相册里，只是这里不展示；如果当时正停在隐私页，会自动退回「建议清理」。
- **隐私分类模糊显示**：打开后，隐私组的缩略图先糊掉，点开大图才看清。默认关（正在校准误报），校准完会改成默认开。

**数据与存储**

- **扫描缓存**：显示当前占多少。清除后下次扫描要重新分析所有照片——**不会删任何照片**，但可能要十几分钟。
- **重新扫描**：等于回首页重新开始。

**系统权限**

- **相册权限**：显示是「全部照片」还是「仅选中的照片」。
- **去系统设置里修改**：直接跳到本 App 的系统设置页。

**关于**

- 版本号 + 构建号、这次分析了多少项、照片处理是否在本机。

## 9. 导出清单

结果页的「导出清单」生成一份纯文本：总数、各类数量、建议清理逐条（时间 + 分数 + 理由）。可以存到文件或发给别人，不包含照片本身。

## 10. 常见问题

**扫完结果全是 0？**
先看首页权限是不是"已允许全部"。如果是"部分照片"，去 设置 → 相册整理 → 照片 改成全部，回来重扫。仍然全 0 就杀掉 App 重开。

**发票票据一直是 0？**
两种可能：① 顶部横幅还在，内容识别没跑完；② 照片太糊或拍得太远，1024px 上也读不出"发票/价税合计"。可以先按"文档"分类找。

**扫到一半退回去了？**
多半是锁屏或切后台被系统挂起。保持前台、别锁屏，重新点扫描。1.4(18) 起已经算过的部分会留在本地，重扫**从断点继续**，不会从头来。

**我装的是哪一版？**
打开 App，首页滑到最底下，有一行「版本 1.4（构建号 20）」。**只看构建号**——版本号 1.4 会同时对应十几个构建号，它们的代码完全不同。也可以到 设置 → 通用 → iPhone 储存空间 → 相册整理 里看，但那里只显示 1.4，不显示构建号。

**「隐私」组里混进了普通照片？**
这是粗筛，一定会有误报，**1.4(20) 已经把误报的主要来源（自拍）压下去**：新算法先找出人脸并整块排除，再看"人体区域里剩下的皮肤占多少"。

穿衣服的人这个比例通常不到 0.2，裸露躯干会到 0.5 以上，所以普通自拍、半身照不该再大量进来了。它仍然分不清泳装和内衣，也分不清"婴儿洗澡"和成人——所以这一组永远需要亲眼看一遍。误报的照片直接忽略即可，它不进「建议清理」，不会在你顺手全选时被带走。1.4(19) 起缩略图暂时不打码，就是为了让你能看清并统计误报率。

**「文档」组变少了？**
1.4(18) 修了误判：以前证件照和举着文件的人像都会被判成文档（因为背景是纸），现在人脸面积够大就先判人物。剩下的才是真的纸面内容。

**删除失败？**
常见于开了"优化 iPhone 存储"、照片还在 iCloud 上没下载完；或权限被改成"部分照片"。到 设置 → 相册整理 → 照片 确认为"全部"，等 iCloud 下载完再试。

**扫描很慢？**
第一次全量扫描要读两万多张缩略图，视相册大小通常几分钟；**之后只算新增和修改过的照片**，几秒到一分钟就能完成。1.4(19) 修了后台缓存写入的 CPU 占用：以前全命中扫描也会在后台烧 90 秒 CPU、写 150 MB，现在没有新增就一次都不写。

**同一张照片出现在"重复"又出现在"相似"？**
"重复"是字节相同，优先级更高；"相似"是看起来像。以重复组为准，相似组里那张可以忽略。

**"建议清理"里出现了我不想删的？**
正常。可疑度是启发式的，收藏、有人脸、发票都已经自动减分，但不可能全对。模糊页里切到单列、点「算清晰」可以永久排除某张；其余靠你自己判断。

**为什么不能深色模式 / 横屏 / iPad？**
自用工具，只服务一台 iPhone 竖屏。固定浅色是设计决定，见 `DESIGN.md`。
